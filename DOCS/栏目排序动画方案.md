# 栏目排序动画方案

## 背景

在栏目管理面板中，点击某个栏目时，它会与上方的栏目交换位置。需要一个动画来表现这个交换过程。

---

## 方案 A：同时滑动交换（当前实现）

**原理**：被点击的 item 向上滑动，同时上方的 item 向下滑动，两者同步完成。

**动画过程**：
```
初始状态:     动画中:          动画结束:
[  A  ]      [  A  ] ↓        [  B  ]
[  B  ]  →   [  B  ] ↑   →    [  A  ]
[  C  ]      [  C  ]          [  C  ]
```

**优点**：
- 视觉流畅，符合物理直觉
- 用户能清楚看到"谁和谁交换了"

**缺点**：
- 实现较复杂，需要同时控制两个 item 的动画
- 动画过程中如果快速点击可能出问题

**代码复杂度**：★★★☆☆

---

## 方案 B：淡入淡出

**原理**：点击后直接交换数据，被移动的 item 做一个 200ms 的透明度变化（半透明 → 不透明）。

**动画过程**：
```
初始状态:     点击瞬间:        动画结束:
[  A  ]      [  B  ] (半透明)  [  B  ] (不透明)
[  B  ]  →   [  A  ]          [  A  ]
[  C  ]      [  C  ]          [  C  ]
```

**优点**：
- 实现简单
- 不会有重叠问题
- 暗示"这个 item 刚刚移动过"

**缺点**：
- 没有位移感，用户可能不清楚交换了什么
- 视觉效果较弱

**代码复杂度**：★☆☆☆☆

---

## 方案 C：背景闪烁

**原理**：点击后直接交换数据，被移动的 item 背景色闪烁一下（主题色 → 恢复）。

**动画过程**：
```
初始状态:     点击瞬间:              动画结束:
[  A  ]      [  B  ] (蓝色背景)     [  B  ] (正常背景)
[  B  ]  →   [  A  ]          →    [  A  ]
[  C  ]      [  C  ]               [  C  ]
```

**优点**：
- 实现简单
- 明确提示"这个 item 刚刚发生了变化"
- 不影响布局

**缺点**：
- 没有位移感
- 闪烁可能显得突兀

**代码复杂度**：★☆☆☆☆

---

## 方案 D：无动画

**原理**：点击后直接交换数据，不做任何动画。

**动画过程**：
```
初始状态:     点击后:
[  A  ]      [  B  ]
[  B  ]  →   [  A  ]
[  C  ]      [  C  ]
```

**优点**：
- 最简单，零 bug 风险
- 性能最好

**缺点**：
- 没有视觉反馈，用户可能不确定发生了什么
- 体验较生硬

**代码复杂度**：☆☆☆☆☆

---

## 对比总结

| 方案 | 视觉效果 | 实现复杂度 | 重叠问题 | 推荐场景 |
|------|----------|------------|----------|----------|
| A 同时滑动 | ★★★★★ | ★★★☆☆ | 无 | 追求最佳体验 |
| B 淡入淡出 | ★★★☆☆ | ★☆☆☆☆ | 无 | 快速实现 |
| C 背景闪烁 | ★★★☆☆ | ★☆☆☆☆ | 无 | 简单提示 |
| D 无动画 | ★☆☆☆☆ | ☆☆☆☆☆ | 无 | 最简实现 |

---

## 当前实现

已按 **方案 A** 实现，动画时长 200ms，使用 `SlideTransition` + `AnimationController`。
