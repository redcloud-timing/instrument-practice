# Instrument Practice - 乐器练习助手

一款面向乐器学习者的日常练习辅助工具，使用 Flutter 构建。

## 功能

- **练习打卡** — 记录每日练习时长和笔记，支持日历视图回顾
- **节拍器** — 可调节速度与拍号，辅助节奏训练
- **音高轨迹** — 实时音高检测、音高轨迹和录音回看
- **乐谱资料库** — 导入和管理 PDF / 图片乐谱，支持收藏和笔记
- **计时器** — 练习计时功能
- **主题换色** — 自由切换应用主题色

## 技术栈

| 技术 | 用途 |
|------|------|
| Flutter / Dart | 跨平台 UI |
| Provider | 状态管理 |
| SQFlite | 本地数据持久化 |
| table_calendar | 日历组件 |

## 开始使用

```bash
# 克隆项目
git clone https://github.com/redcloud-timing/flute-practice.git

# 安装依赖
flutter pub get

# 运行
flutter run
```

## 环境要求

- Flutter SDK ^3.11.5
- Dart SDK ^3.11.5
